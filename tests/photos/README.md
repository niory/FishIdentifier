# Фото для проверки

Восемь JPEG с Wikimedia Commons, по два на каждую широкую категорию модели.
Источники, авторство, лицензии и контрольные суммы указаны в `sources.json`.
Для каждого изображения действует его исходная лицензия; общая лицензия проекта
не заменяет условия использования фотографий. Изображения скачаны как превью шириной 960 px.

Ожидаемые категории выбраны по описаниям файлов, до запуска модели. У сома, гурами
и окуня в подборке по два разных вида; модель содержит только общие английские
названия и не описывает, на каких видах обучалась. Эта подборка предназначена
для быстрой проверки, а не для оценки обобщающей способности модели.

Повторное скачивание: `python3 scripts/download-photos.py` из корня репозитория.
Результат: `npm run build && npm run test:photos`.
